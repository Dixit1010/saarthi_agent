# Build: Saarthi AI — Autonomous Job Search & Application Agent

You are a senior staff-level full-stack engineer, AI engineer, browser automation engineer, and product architect.

I want you to build a production-quality AI-powered job search and application platform called **Saarthi AI**.

The goal is to turn an existing job-hunt workspace into an intelligent job-search agent that can:

1. Discover relevant jobs automatically.
2. Parse and understand job descriptions.
3. Match jobs against the user's profile, skills, experience, preferences, and resume.
4. Score and rank jobs based on transparent matching criteria.
5. Generate a JD-specific tailored resume without fabricating experience.
6. Generate tailored cover letters and application answers.
7. Autofill application forms using browser automation where permitted.
8. Ask for human approval before final submission by default.
9. Track every application and its status.
10. Run scheduled job discovery automatically.
11. Maintain a complete audit trail of agent actions.
12. Learn from the user's application history and preferences without silently changing important criteria.

The product should feel like a **personal AI job-search employee**, not a simple job board.

---

# 1. IMPORTANT PRODUCT PRINCIPLES

## Accuracy over automation

Never invent:

* employment experience
* years of experience
* companies
* projects
* technologies
* certifications
* education
* achievements
* salary
* job titles
* responsibilities

The AI may rephrase existing facts but may not create new facts.

Every generated resume bullet should be traceable to information in the user's master profile, experience bank, project bank, or verified application history.

---

# 2. HUMAN CONTROL

The default mode must be:

DISCOVER → ANALYZE → TAILOR → PREPARE → HUMAN REVIEW → SUBMIT

Do NOT automatically submit applications by default.

Provide three automation modes:

### MANUAL

The agent only discovers and analyzes jobs.

### ASSISTED

The agent:

* finds job
* scores it
* generates resume
* generates answers
* opens application
* fills fields
* stops before final submission

User clicks:

"Approve & Submit"

### AUTONOMOUS

Allow auto-submission only when:

* the user explicitly enables it
* the site/application flow is supported
* there are no sensitive or ambiguous questions
* all required answers are derived from verified user data
* no CAPTCHA or anti-bot challenge is encountered
* no unsupported terms or commitments are required

If any unsafe/ambiguous situation appears, pause and ask the user.

Never bypass CAPTCHA, anti-bot mechanisms, authentication protections, rate limits, or access controls.

Respect website terms, robots rules where applicable, and official APIs/integrations where available.
